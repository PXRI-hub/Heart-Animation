# Particle Heart Animation ❤️

A 3D heart made from animated particles using JavaScript.

## About the Project

I built this project as a creative experiment with particle effects, animation, and 3D graphics.

The heart is made up of individual particles that come together to create the final shape while continuously moving and rotating while beating like a regular heart.

## Features

- Animated particle heart
- Smooth rotation
- 3D particle effects
- Responsive browser-based animation

## Built With

- JavaScript
- HTML
- CSS
- Three.js

## What I Learned

This project helped me experiment more with Three.js and understand how particles, animation loops, and 3D movement can be used to create visually interesting effects in the browser.

## Live Demo

The animation can be viewed directly in the browser through GitHub Pages.
